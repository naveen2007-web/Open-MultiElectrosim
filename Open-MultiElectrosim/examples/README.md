# Importable starter projects

Use Export → Import an existing project in the app and select any `.ome.json` file here. The same starters are also available from Examples.

- `rc.ome.json`: RC low-pass, sine source, two differential probes.
- `divider.ome.json`: 10 V / two equal 1 kΩ resistors / 5 V midpoint.
- `logic.ome.json`: AND followed by NOT, with toggle inputs.
- `blink.ome.json`: powered Arduino logical GPIO interpreter driving an LED through 330 Ω.
- `opamp.ome.json`: finite-gain voltage follower.
- `pcb.ome.json`: complete LED circuit with a compact routed board; zero issues under implemented DRC checks.
- `routed-led-driver.kicad_pcb`: directly exported generic LED board for KiCad review.

The KiCad file is a generic starting point, not a manufacturer-qualified layout. Read README.md and docs/MODELS.md before fabrication or drawing conclusions about real hardware.
