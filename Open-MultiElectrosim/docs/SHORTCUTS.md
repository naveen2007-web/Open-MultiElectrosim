# Keyboard and mouse controls

| Action | Shortcut |
| --- | --- |
| Search library | / |
| Cancel placement / wire; select mode | Esc |
| Wire / route copper | W |
| Pan tool | H |
| Pan temporarily | Hold Space + drag, or middle-button drag |
| Run / pause | Tap Space outside text inputs |
| Rotate clockwise / counterclockwise | R / Shift+R |
| Flip wire bend | X |
| Set first bend direction | Left / Right arrow while routing |
| Remove latest bend | Backspace while routing |
| Insert via and change copper layer | V while routing PCB |
| Undo / redo | Ctrl+Z / Ctrl+Shift+Z (Cmd on macOS); Ctrl+Y also supported |
| Duplicate selected part | Ctrl+D |
| Delete selected item | Delete |
| Fit to view | F |
| Zoom | Scroll or + / − |
| Save | Ctrl+S |
| Toggle dark/light | T |
| Help | ? |

Shortcuts are disabled while editing input fields. Enter in inspector fields applies properties. You can also click **Apply properties**. Choose a wire palette color before starting a connection or select an existing wire to recolor it. Right-angle bends can be chosen manually; PCB segments may also be diagonal after moving footprints. Use DRC and reroute after moving parts.
